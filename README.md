# ☁️ AWS Cloud Labs

> 🚧 **Status:** Planned — labs will be documented here as they're completed.

Hands-on AWS labs supporting progress toward **AWS Certified Cloud Practitioner**.

## Planned labs
- **EC2 basics** — launch, connect to, and secure a Linux instance
- **S3 static hosting** — host a static site with versioning enabled
- **IAM fundamentals** — users, groups, roles, and least-privilege policies
- **Billing alarms** — cost monitoring and budget alerts

## Goals
- Practical cloud skills for cloud support roles
- Foundation for the AWS Certified Cloud Practitioner exam
